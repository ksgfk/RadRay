# Runtime 与 RHI 阶段二实施记录

2026-11-21 开始。基线为阶段二计划归档后的 `develop` 工作树。

## 局部附件视图的准备与合并

原实现有两处独立的默认视图查找。准备阶段预建 mip 0 视图，随后组装物理光栅 Pass 时还会按默认范围查找一次。仅修改附件声明会导致非零 mip 的清屏仍绑定旧视图。两处须使用编译阶段归一化的同一范围，同时保留显式外部视图的所有权。回归用例需检查实际交给 RHI 的视图和矩形。

两处现已共用附件视图解析。通用范围归一化接受单一深度或模板 aspect，而 RHI 要求组合格式的深度模板附件视图包含两者；构图阶段同步校验这一限制。定向 CTest 首轮 14 项通过，包括双后端逐像素读回两个 mip、两个数组层及局部清屏边界，以及外部查询池跨越清屏覆写的时间戳回读。

## D3D12 块压缩尾级读回

按计划直接把逻辑宽高写入源框后，真设备测试在 BC1 的 1 × 1 mip 上触发 D3D12 调试层消息 873。源框的右、下边界也必须按 4 × 4 压缩块对齐。D3D12 后端改用覆盖该区域的完整物理块构造源框。公共 API 和 Vulkan 保持逻辑纹素范围。回归测试读回尾级全部 8 个字节并与上传的压缩块比较。

哨兵测试在同一命令缓冲中先用缓冲拷贝填充读回目标，再用图像拷贝只覆盖指定行。Vulkan 同步验证报告两次写之间缺少依赖。测试在两次写之间加入 CopyDestination 到 CopyDestination 的缓冲屏障。复跑 16 项全部通过，涵盖两个后端的压缩尾级、非零偏移、带间隙的体纹理、单平面深度复制遮挡及异步子区域读回。

## Vulkan 丢失态的可见时机

首次检出设备丢失的线程负责调用原生 idle。仅在等待之前设置一个布尔标志时，另一线程可以先观察到丢失并开始销毁在途资源。设备现在分别记录丢失锁存和收尾同步完成，观察者返回丢失结果前等待后者。交换链排空本身检出丢失时复用原生等待。测试用按设备分派的 Vulkan 调用表记录 idle、时间线、交换链与设备销毁顺序，已验证首次由队列提交或交换链排空检出时均只等待一次。

完整 Debug 构建成功。设备丢失与深度格式定向 CTest 共 11 项通过。全量 CTest 注册 965 项，962 项通过，3 项 Vulkan 到 D3D12 的外部缓冲、纹理和围栏互操作测试按能力跳过。文档检查和差异空白检查通过。

## Vulkan 颜色写掩码

深度遮挡绘制在 Vulkan 上意外写入了白色。转换函数用 switch 枚举了六个常用掩码，零掩码和部分通道组合会落入不可达分支。现按位保留全部四个通道，在建管线前拒绝未知位。回归测试逐一检查 16 种合法组合及越界位。

补入写掩码回归后的 Debug 全量 CTest 共 966 项。963 项通过，3 项 Vulkan 到 D3D12 的外部缓冲、纹理与围栏互操作按设备能力跳过，0 项失败。D3D12 与 Vulkan 的局部附件、顺序屏障、颜色子区域读回和深度拷贝用例均在 RTX 4080 上执行。
